WASD / arrow keys or controllers.

Controls

Move with the left stick, D-pad, WASD, or arrow keys. Build speed to hit harder. Push others outside the shrinking arena. Last player inside wins; ties share the win.

Space or controller Start pauses. R starts the next round.

Multiplayer

Press a controller button to join. With two players, click Start round or press controller Start. Add keyboard players below.

Eight physical controllers need a compatible browser and operating system.

Free play

No timer or knockouts. Start with one or more players. Player cards show live inputs; CPU means a computer player.
